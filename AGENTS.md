# WeReach project instructions

- The canonical personal repository is https://github.com/FretterR/WeReach.git.
- The owner requested that future authorized WeReach changes be committed and pushed here by default. Check remote changes first, preserve others' work, and never force-push. Report the commit and any push failure. Publishing the website is a separate action.
- Keep work within requested scope, using one agent and minimal dependencies.
- Use React, TypeScript, Vite, and plain CSS. Do not add paid services, accounts, or a backend without a feature request that needs them.
- Keep opportunity data in src/data.ts. Fictional examples must stay labeled; never invent real contact details or current needs.
- Cleaning Products is a separate category from Hygiene and Household.
- Preserve responsive layouts, keyboard accessibility, and missing-data handling.
- Run the production build and focused tests before pushing. Update README.md when setup, data, or behavior changes.
- Do not commit node_modules, dist, credentials, or local preview captures.
